## 1. 引言与实验设置

随着工艺节点向 45 nm 以下推进，特征尺寸缩减与存储系统性能之间的关系愈发复杂。尽管尺寸缩减通常能降低单元面积和互连线电容，但单元拓扑、互连层次结构与优化器所选缓存组织形式之间的相互作用，在性能-功耗-面积设计空间中引入了复杂且往往非单调的行为。本分析采用 DESTINY 仿真器，在四个典型工艺节点（65 nm、45 nm、32 nm 和 22 nm）上评估四种存储器技术：平面 SRAM（2D SRAM）、堆叠双层 SRAM（3D SRAM）、平面嵌入式 DRAM（2D eDRAM）以及堆叠双层 eDRAM（3D eDRAM）。辅助实验在固定的 3D SRAM 配置下扫描三个 TSV（硅通孔）工艺参数，以量化系统级指标对 TSV 建模假设的敏感性。

全部 22 次仿真共享统一的归一化基准配置，以确保所观察到的差异反映技术选型与节点差异，而非配置偏差：2 MB 容量，256 位字宽，1 路组相联，LOP（低功耗工作）器件路线，350 K 工作温度，H 树全局布线，以及 WriteEDP 作为优化目标。WriteEDP 指标——写入能量与写入延迟之积——引导 DESTINY 内部优化器在每个配置点选择能最小化该复合代价函数的缓存存储体组织方式（子阵列数量、Mat 数、位单元阵列尺寸）。

从每次仿真中提取五个指标：总芯片面积（mm²）、缓存命中（读取）延迟（ns）、缓存写入延迟（ns）、写入动态能耗（nJ/次）和总泄漏功耗（mW）。完整数据集如表 1 所示。

## 2. 面积缩放分析

### 2.1 观测趋势

随着工艺节点从 65 nm 缩减至 22 nm，四种技术的总芯片面积均单调减小，这与特征尺寸缩小带来更高位密度的基本预期一致。然而，各技术的缩减幅度存在显著差异：2D SRAM 实现 6.7 倍缩减（12.348 → 1.836 mm²），3D SRAM 实现 7.3 倍（7.105 → 0.969 mm²），2D eDRAM 实现 9.5 倍（5.957 → 0.630 mm²），3D eDRAM 实现 14.1 倍（7.743 → 0.550 mm²）。这些缩放比例背后存在两种截然不同的物理机制——单元级缩放与三维集成——需要加以区分。

### 2.2 单元级缩放机制

SRAM 单元为六晶体管（6T）交叉耦合反相器对，含两个存取晶体管。其最小面积受制于维持足够静态噪声裕量（SNM）的需求，该需求限制了宽长比的激进缩放。在 DESTINY 的 LOP 模型中，每比特 SRAM 面积大致按 F²（F 为半节距）缩减，但受多晶体管单元拓扑的固有开销约束，比例系数偏离理想值。2D SRAM 面积从 12.35 mm² 降至 1.84 mm²，约为 6.7 倍，与几何期望 (65/22)² ≈ 8.7 倍相比偏低，差异来源于外围电路和布线结构的固定开销。

eDRAM 的单元拓扑——单存取晶体管加单存储电容（1T-1C）——在面积效率上本质优于 SRAM。在大工艺节点时，电容占据单元面积的较大比例；随节点缩减，电容面积相对于晶体管栅极节距的缩减更为激进。因此，2D eDRAM 在相同节点范围内实现 9.5 倍缩减，显著优于 2D SRAM 的 6.7 倍。这与既有文献的结论一致：DRAM 族单元从每个节点演进中获得的收益多于受 SNM 和泄漏约束的 SRAM 单元。

### 2.3 三维堆叠对面积的影响

在每个节点对比二维与三维方案，可以揭示垂直堆叠在系统层面的净影响。对于 SRAM，三维堆叠在所有节点均实现 42–50% 的占用面积缩减：65 nm 时 3D SRAM 为 7.11 mm² 对比 2D SRAM 的 12.35 mm²（−42%）；32 nm 时缩减幅度达到 50%（2.13 对比 4.26 mm²）。DESTINY 模型设定 StackedDieCount = 2、精细分区（PartitionGranularity = 0），实质上将存储阵列分布在两个键合芯片上，以 TSV 插入开销为代价将平面面积减半。对于基准二维单元本身已足够大、可吸收 TSV 开销的 SRAM 而言，堆叠带来的面积收益始终接近理论上的 2 倍缩减。

对于 eDRAM，三维堆叠收益强烈依赖于工艺节点。65 nm 时，3D eDRAM 的占用面积（7.74 mm²）比其二维对应物（5.96 mm²）*大* 30%。这一反转现象的根源在于：大特征尺寸下，TSV 结构及其相关隔离保护区消耗了芯片面积的相当一部分。65 nm 时 eDRAM 的 1T-1C 单元每比特面积已相对较小，因此叠加的 TSV 开销占总面积的比例不可忽视。当节点缩减至 45 nm 时，3D eDRAM 相对 2D eDRAM 实现了 31% 的面积缩减，表明对于本实验特定容量（2 MB）和 TSV 投影设置（LocalTSVProjection = 0，激进模式），芯片减半收益超越 TSV 开销的交叉点位于 65 nm 与 45 nm 之间。22 nm 时，3D eDRAM（0.550 mm²）相对 2D eDRAM（0.630 mm²）仅改善 13%，反映出随着 eDRAM 单元趋于极度紧凑，理论上的 2 倍堆叠收益被残余 TSV 开销部分抵消。尽管如此，22 nm 下的 3D eDRAM 在所有测试配置中仍具有最小的绝对占用面积：0.55 mm²，约为 65 nm 下 2D SRAM 的 1/22。

3D eDRAM 相对 3D SRAM 具有更高的总体缩放比（14.1× 对比 7.3×），可理解为 eDRAM 更快的单元级缩放与三维集成复合效益的乘积——而三维集成在更精细节点下 TSV 开销趋于可忽略时收益更为显著。

## 3. 读取延迟分析

### 3.1 观测趋势

缓存命中（读取）延迟在不同技术之间呈现出本质不同的行为特征。3D eDRAM 是唯一在所有四个节点均实现严格单调延迟改善的技术：0.538 → 0.504 → 0.472 → 0.420 ns。其他所有技术均呈现非单调行为，SRAM 最为突出：2D SRAM 在 65 nm 时的延迟为 9.942 ns，是其 45 nm 值（0.939 ns）的十倍以上；3D SRAM 呈现类似但幅度较小的异常（65 nm 时 4.698 ns 对比 45 nm 时 0.654 ns，比值约 7.2）。此后，SRAM 延迟从 45 nm 到 22 nm 略有上升（2D SRAM：0.939 → 1.184 ns），表明在最精细节点处存在轻微的延迟劣化趋势。2D eDRAM 与 3D SRAM 在 32–22 nm 时延迟范围相近（0.63–0.79 ns），而 3D eDRAM 在所有节点均保持领先。

### 3.2 互连主导延迟与阵列组织的作用

在 DESTINY 的缓存模型中，总访问延迟分解为单元存取时间（t_cell）、Mat 内局部线延迟（t_local）与 H 树全局互连延迟（t_global）之和。在 2 MB 规模下，H 树延迟通常占主导地位，其缩放关系为：

t_global ∝ √A × (单位长度导线电阻 × 单位长度导线电容)

其中 A 为总阵列面积，导线参数由工艺决定。对于给定工艺节点，优化器选择存储体数量、每存储体的 Mat 数以及子阵列尺寸以最小化 WriteEDP。在精细节点下，面积小，H 树短，t_global 较小。然而，65 nm 下 2D SRAM 占用 12.35 mm²，意味着 H 树分支漫长，对应的延迟极大。优化器若不将阵列重组为更浅但更宽的存储体层次，则无法消除这一开销——而那样做会增加能耗。在 WriteEDP 最小化的目标函数下，延迟被牺牲以压低能量项，由此产生了观测到的 9.942 ns 访问时间。这并非 SRAM 技术的物理极限，而是在 WriteEDP 框架下，大面积 65 nm 芯片不可避免的互连代价与优化器目标函数共同作用的结果。

3D SRAM 的异常（65 nm 时 4.698 ns）遵循相同逻辑，但由于三维封装后每个裸片占用面积约缩减 2 倍，H 树分支变短，t_global 有所降低，故异常程度得到部分缓解。

### 3.3 3D eDRAM 的延迟优势

3D eDRAM 在所有节点均取得最低延迟，原因来自两个相互叠加的因素。其一，1T-1C 单元的内在存取时间低于 SRAM 单元，因为单晶体管存取路径向位线呈现的栅极和扩散电容更小。其二，三维堆叠使阵列在垂直方向分布，进一步降低每裸片占用面积，从而缩短 H 树。22 nm 时，3D eDRAM 访问时间 0.420 ns 相比 2D SRAM（1.184 ns）快 3.0 倍，相比 2D eDRAM（0.790 ns）快 1.7 倍。

3D eDRAM 延迟从 65 nm 到 22 nm 的单调改善（0.538 → 0.420 ns），与单位长度导线电容的持续降低及芯片占用面积的不断缩减相吻合。对于其他技术，WriteEDP 驱动的优化器重组以及能量与延迟之间的权衡，部分抵消了上述物理改善，导致 45 nm 之后出现轻微的非单调性。

### 3.4 45 nm 之后 SRAM 延迟的轻微上升

45 nm 之后，SRAM（2D 和 3D 均如此）呈现延迟小幅上升趋势：2D SRAM 为 0.939 → 1.061 → 1.184 ns。若仅考虑更小节点带来更快电路的直觉，这一现象颇为违反常识。在 WriteEDP 优化下，随着节点缩减，能量项的相对权重上升——因为选择高并发度组织（可最小化延迟）所带来的能耗代价，随同时切换的导线和晶体管数量增加而增大。优化器因此在 32 nm 和 22 nm 时倾向于选择更节能（但延迟代价更高）的配置。若改用 ReadLatency 作为优化目标，这一趋势很可能反转，如第 9.2 节所述。

## 4. 写入动态能耗分析

### 4.1 非单调缩放行为

写入动态能耗是本数据集中最反直觉的指标。它并非随节点缩减单调降低，而是对 SRAM 方案呈现出强烈的非单调性：2D SRAM 能耗在 45 nm 时达到峰值（0.173 nJ），约为其 65 nm 值（0.022 nJ）的八倍，随后降至 22 nm 时的 0.035 nJ。3D SRAM 呈现相同模式：0.037 → 0.132 → 0.089 → 0.027 nJ。eDRAM 方案的变化规律更为规则——2D eDRAM：0.092 → 0.117 → 0.066 → 0.019 nJ（45 nm 处有轻微峰值），3D eDRAM：0.206 → 0.102 → 0.061 → 0.021 nJ（单调递减）。

### 4.2 物理机制：配置重组导致的能耗变化

缓存阵列的动态写入能耗由以下关系决定：

E_write = C_switched × V_DD² × α

其中 C_switched 为每次写访问的总切换电容，V_DD 为电源电压，α 为活动因子。原则上，随节点缩减 C_switched 和 V_DD 均降低，意味着能耗应单调减小。观测到的峰值表明，由优化器所选缓存组织形式决定的 C_switched 并不单调降低。

65 nm 时，鉴于单元面积较大，DESTINY 为最小化 WriteEDP 选择了紧凑的低并发度配置：同时切换的子阵列较少，C_switched 保持较低水平，尽管物理尺寸较大。45 nm 时，更小的单元面积使优化器得以选择高并发度的组织方式——每次访问激活更多 Mat、更多位线切换——从而降低写入延迟（改善 EDP 中的延迟项），代价是 C_switched 增大。这一重组所带来的 C_switched 增量超过了电压缩放的收益，导致能耗升高。到 32 nm 和 22 nm 时，持续的电压缩放及额外并发度所带来的边际延迟收益趋于饱和，优化器重新倾向于节能型配置，能耗随之恢复预期的降低趋势。

对于 3D eDRAM，即使在 65 nm 节点，其每裸片占用面积已相对紧凑，优化器的起点就已处于较高并发度状态。因此，随 V_DD 和单元电容的缩减，能耗单调降低，不存在 SRAM 所表现出的重组诱导峰值。

### 4.3 22 nm 节点的能耗收敛

22 nm 时，四种技术的写入能耗收敛至 0.019–0.035 nJ/次 的窄小范围内。这一收敛反映了精细节点下电源电压缩放的主导地位：随 V_DD 降低，能耗表达式中 V_DD² 因子强制驱使所有技术向相近的绝对能耗值靠拢，无论 C_switched 差异如何。这也意味着在 22 nm 节点，SRAM 与 eDRAM 之间的写入能耗差异基本消失，竞争格局的核心转向面积和泄漏功耗。

## 5. 泄漏功耗分析

### 5.1 eDRAM 的泄漏功耗优势

泄漏功耗是本数据集中跨技术趋势最一致、物理机制最清晰的指标。在所有数据点上，eDRAM 泄漏功耗均低于 SRAM，差距在约 2.1 倍（3D eDRAM 对比 3D SRAM，65 nm：107.0 对比 145.8 mW）到 23.9 倍（2D eDRAM 对比 2D SRAM，32 nm：30.0 对比 234.6 mW）之间。全部可比节点对的泄漏功耗比中位数约为 5–8 倍。

这一优势根植于单元拓扑。SRAM 的 6T 单元包含六个晶体管，每个均贡献亚阈值泄漏电流 I_sub ∝ exp(−V_th / n·V_T)，其中 V_th 为阈值电压，n 为亚阈值斜率因子，V_T 为热电压。对于 2 MB 阵列中数百万个单元而言，累积的待机泄漏相当可观。eDRAM 的 1T-1C 单元仅含单个存取晶体管；存储电容为无源器件，稳态下不存在直流泄漏路径。这种六比一的晶体管数量差异（6T SRAM 对比 1T eDRAM）在很大程度上解释了观测到的泄漏优势，尽管具体比值随 LOP 路线中各节点的 V_th 调整而有所变化。

### 5.2 三维堆叠对泄漏的影响

相较于二维方案，三维集成在所有情况下均增加泄漏功耗。65 nm 时，3D SRAM（145.8 mW）比 2D SRAM（124.0 mW）高 18%；22 nm 时，3D SRAM（70.3 mW）比 2D SRAM（65.8 mW）高 7%。对于 eDRAM，增幅更为显著：3D eDRAM 泄漏在各节点均为 2D eDRAM 的 1.65–4.37 倍（例如 22 nm：16.2 对比 9.8 mW，增幅 65%）。三维集成带来的额外泄漏来源于三个方面：（1）每个裸片上的 TSV 驱动与接收电路；（2）第二裸片上的额外外围逻辑；（3）用于良率管理的冗余 TSV 电路所带来的总晶体管数量增加。在大工艺节点时，由于紧凑 eDRAM 方案的基准单元泄漏相对较低，这些开销电路的相对贡献更为突出。

### 5.3 泄漏功耗随节点的缩放

对于 eDRAM，泄漏功耗与面积趋势密切相关：2D eDRAM 泄漏从 24.5 mW 降至 9.8 mW，缩减约 2.5 倍，大致与 9.5 倍面积缩减相应（非线性关系反映了 LOP 模型中与节点相关的 V_th 变化）。对于 SRAM，32 nm 处的异常峰值严重破坏了泄漏的缩放规律，详见第 6.2 节。

## 6. 异常行为的物理解释

### 6.1 异常 A：65 nm 时 SRAM 延迟突增

65 nm 时，2D SRAM 读取延迟为 9.942 ns——比其 45 nm 值（0.939 ns）高出十倍以上。3D SRAM 的对应值为 4.698 ns 对比 0.654 ns（比值约 7.2）。任何 eDRAM 配置均未出现此类不连续性。

这一异常并非制造缺陷或仿真伪影，而是优化器在 WriteEDP 目标下，对 65 nm 节点大芯片面积响应的直接结果。65 nm 下 2D SRAM 阵列占用 12.348 mm²；在如此大的芯片上组织一个 2 MB、256 位宽的缓存，DESTINY 选择了深度层次化的存储体-Mat 结构。在此大占用面积上分发地址和数据所需的全局 H 树，引入了主导访问时间的导线延迟。由于 WriteEDP 对能量与延迟之积施加惩罚，且优化器可以通过接受更高延迟来大幅降低能量（选择更少同时活动的 Mat 减少切换电容，但增加了需穿越的 H 树层级），WriteEDP 最小化设计点在 65 nm 时选择了一种 H 树延迟极高的组织方式。

45 nm 时，面积缩减约 2.34 倍（从 12.348 降至 8.893 mm²），使 H 树深度充分收缩，优化器可以找到延迟与能量在 EDP 中相对均衡的配置，由此得到观测到的 0.939 ns 结果。3D SRAM 情况定性相同，但由于三维方案在 65 nm 时的占用面积（7.105 mm²）小于二维情况，初始 H 树较浅，异常程度有所减轻，最终呈现为 4.698 ns。

这些结果应被理解为 WriteEDP 框架下优化器选择的设计点，而非 SRAM 技术固有的延迟上限。若以 ReadLatency 为优化目标，65 nm 设计的访问延迟将大幅降低，代价是更高的能耗。

### 6.2 异常 B：32 nm 时 SRAM 泄漏突增

2D SRAM 和 3D SRAM 在 32 nm 时的泄漏功耗均为 234.6 mW——约为 45 nm 值（48.3 和 51.3 mW）的 5 倍，约为 22 nm 值（65.8 和 70.3 mW）的 3.6 倍。原始输出中两者数值完全相同（均为 234.632 mW），证实优化器在该节点为 2D 与 3D SRAM 收敛至相同的物理配置。eDRAM 方案未出现此类突增。

其物理机制涉及缓存阵列泄漏的构成。DESTINY 中的总泄漏包含活跃与非活跃子阵列中所有晶体管的亚阈值泄漏。当优化器选择高并发度配置时——众多子阵列共享数据路径，且在访问期间均须预充电并保持就绪状态——贡献待机泄漏的总晶体管数量相应增加。在 32 nm 的 WriteEDP 优化下，最小化写入能量与写入延迟之积需要高子阵列并发度（以降低写延迟，改善 EDP 的延迟项）。这种高并发度组织大幅增加了同时偏置的晶体管数量，从而显著提升总亚阈值泄漏。

2D 与 3D SRAM 在 32 nm 的泄漏值完全相同，进一步支持了上述解释：WriteEDP 目标函数驱使优化器选择与裸片堆叠方式无关的相同基本子阵列组织，因为主要代价驱动因子是存储单元和子阵列晶体管数量，而非裸片分区方式。eDRAM 对此免疫，是因为其 1T-1C 单元每比特泄漏晶体管数量极少，相同并发度增量所带来的绝对泄漏跳升远小于 SRAM。

## 7. 32 nm 节点的跨技术比较

选取 32 nm 节点作为代表性比较基准，原因在于：该节点位于扫描范围的中段，规避了 65 nm 的极端异常，同时代表了工业界充分验证的工艺代际。

**表 2. 32 nm 节点多指标比较**

| 技术 | 面积 (mm²) | 读延迟 (ns) | 写能耗 (nJ) | 泄漏 (mW) |
|---|---|---|---|---|
| 2D SRAM  | 4.262 | 1.061 | 0.123 | 234.6 |
| 3D SRAM  | 2.132 | 0.633 | 0.089 | 234.6 |
| 2D eDRAM | 1.440 | 0.757 | 0.066 |  30.0 |
| 3D eDRAM | 1.068 | 0.472 | 0.061 |  50.1 |

在 32 nm 节点，3D eDRAM 在四个主要指标中的三项上居于领先：最小面积（1.068 mm²，为 2D SRAM 的 1/4）、最低读取延迟（0.472 ns，比 2D SRAM 快 2.2 倍）和最低写入能耗（0.061 nJ，比 2D SRAM 低 2 倍）。唯一不占优的指标为泄漏功耗，其中 2D eDRAM（30.0 mW）比 3D eDRAM（50.1 mW）低 40%，原因在于堆叠配置中额外的 TSV 和外围电路。

3D SRAM 提供了一个颇具竞争力的折中方案：其面积（2.132 mm²）为 2D SRAM 的 50%，仅为 3D eDRAM 的两倍；读取延迟（0.633 ns）与 2D eDRAM（0.757 ns）相当。然而，两种 SRAM 方案均承受相同的 234.6 mW 泄漏代价，在任何功耗受限的应用场景中都是显著劣势。对于延迟不敏感而待机功耗占主导的工作负载，2D eDRAM 兼具 1.440 mm² 占用面积与 30.0 mW 泄漏功耗的组合可能是最优选择。

需要特别指出的是，DESTINY 的指标集不包含 eDRAM 的刷新能耗。在真实实现中，1T-1C 电容的周期性刷新操作会增加与刷新频率成正比的基础功耗，而刷新频率由单元保持时间（本实验设为 40 µs）和总比特数共同决定。对于 2 MB 阵列，刷新能耗可额外增加数毫瓦的功耗，部分侵蚀 eDRAM 的泄漏优势。SRAM 指标中不存在这一开销，任何完整的系统级评估都必须将其纳入考量。

## 8. TSV 参数敏感性分析

### 8.1 实验设计

实验二保持技术（32 nm 下的 3D SRAM）和全部缓存配置参数不变，独立扫描三个 TSV 工艺参数：LocalTSVProjection（0 = 激进，1 = 标准，2 = 保守），GlobalTSVProjection（相同档位），以及 TSVRedundancy（1.0、1.2、1.5，分别对应 0%、20%、50% 的额外 TSV 冗余比例，用于良率管理）。

**表 3. TSV 敏感性实验结果（3D SRAM @ 32 nm）**

| 参数 | 档位 0/1.0 | 档位 1/1.2 | 档位 2/1.5 | 最大面积变化 | 最大写能耗变化 |
|---|---|---|---|---|---|
| LocalTSVProjection  | 2.132 mm², 0.089 nJ | 2.250 mm², 0.093 nJ | 2.139 mm², 0.095 nJ | +5.5% | +6.7% |
| GlobalTSVProjection | 2.132 mm², 0.089 nJ | 2.149 mm², 0.090 nJ | 2.133 mm², 0.090 nJ | +0.8% | +1.1% |
| TSVRedundancy       | 2.132 mm², 0.089 nJ | 2.132 mm², 0.090 nJ | 2.133 mm², 0.090 nJ | <0.1% | +1.1% |

全部九个配置的读取延迟均为 0.633 ns，写入延迟均为 0.423 ns——对 TSV 参数变化完全不敏感。

### 8.2 局部与全局 TSV 的面积影响差异

LocalTSVProjection 具有最大的面积影响（档位 1 时 +5.5%），这是因为局部 TSV 在每个子阵列内部直接连接两个堆叠裸片，其节距和隔离保护区直接占用与位单元阵列竞争的面积。将 LocalTSVProjection 从 0（激进）提升至 1（标准），总占用面积增加 0.118 mm²。面积变化的非单调性——从档位 0 到档位 1 增大，从档位 1 到档位 2 部分恢复——表明 DESTINY 的优化器在保守投影下重构了局部互连：当局部 TSV 面积较大时，优化器通过减少每个子阵列的 TSV 连接数量（代价是写入能耗略有上升）来实现部分面积回收。

GlobalTSVProjection 的影响显著较小（最大 +0.8%），原因在于全局 TSV 布置在存储体层级，其面积代价分摊至规模更大的阵列占用面积上。在 2 MB 缓存规模下，全局 TSV 数量由字宽和控制总线需求决定，对总芯片面积的贡献处于边际量级。TSVRedundancy 对面积的影响几乎为零（<0.1%），因为用于良率改善而增加的冗余 TSV 被布置在基准布局中已预留的保留区内。

### 8.3 延迟的完全不敏感性

读写延迟对所有 TSV 参数变化的完全不敏感性（九个配置下分别恒为 0.633 ns 和 0.423 ns），是实验二最重要的发现。这意味着该 32 nm 下 2 MB 缓存的关键时序路径不经过任何 TSV 互连——无论是局部还是全局。这与 DESTINY 的架构模型相吻合：跨裸片的 TSV 交叉被纳入局部线层级，主导延迟分量仍为裸片内部的 H 树延迟。只要 TSV 延迟小于 H 树延迟预算，TSV 工艺投影的变化就不会传播至系统级延迟指标。

### 8.4 写入能耗的敏感性

延迟对 TSV 参数免疫，但写入能耗对 LocalTSVProjection 存在轻微敏感性：基准 0.089 nJ，档位 1：0.093 nJ（+4.5%），档位 2：0.095 nJ（+6.7%）。与面积趋势不同，写入能耗随 LocalTSVProjection 档位单调增加。这表明优化器在保守 TSV 投影下重构的局部互连，尽管部分回收了面积，却引入了更高的每次写操作切换电容：保守 TSV 节距带来的更长或更高阻抗局部互连路径，增加了写访问期间需要驱动的电容。GlobalTSVProjection 和 TSVRedundancy 对写入能耗的影响均至多为 1.1%，处于仿真器数值精度的噪声水平之内。

### 8.5 实践意义

TSV 敏感性实验的综合结论是：在 2 MB 缓存规模和 32 nm 工艺节点下，TSV 工艺假设的选择（激进对比保守工艺投影）对系统级指标的影响极为有限。最坏情况——LocalTSVProjection = 2 叠加 TSVRedundancy = 1.5——至多使面积增加 5.5%，写入能耗增加 6.7%，而延迟保持不变。这一结论为设计团队提供了实践指导：采用保守 TSV 投影进行稳健性设计，不会对系统性能造成显著惩罚；TSV 工艺建模的不确定性，对于此类规模的存储器系统而言，不构成一阶设计风险。

## 9. 综合讨论

### 9.1 技术选型的权衡综合

四维性能空间（面积、延迟、能耗、泄漏）并不在所有指标和所有节点上存在单一的绝对优势技术。然而，综合分析揭示了若干具有实践意义的结论。

对于延迟敏感型应用（如高性能处理器的末级缓存），3D eDRAM 在所有节点持续提供最低读取延迟（0.54 → 0.42 ns），同时实现最高面积密度。代价是泄漏功耗相对偏高（32 nm 时 50.1 mW 对比 2D eDRAM 的 30.0 mW）以及未建模的刷新开销。对于能够有效管理刷新的设计（例如通过自适应保持电压技术或数据迁移策略），3D eDRAM 是极具吸引力的选择。

对于功耗受限的应用——嵌入式系统、物联网存储器层次，或任何具有严格空闲功耗预算的设计——32 nm 下的 2D eDRAM 以最低泄漏（30.0 mW）、可接受面积（1.440 mm²）和具有竞争力的延迟（0.757 ns）的组合提供最优选择。3D SRAM 则提供了一个折中方案：面积优于 2D SRAM，同时避免了 eDRAM 的刷新复杂性，但在特定节点继承了 SRAM 的高泄漏代价。

### 9.2 优化器效应与指标解读

理解本研究全部结论须牢记一个关键限定条件：DESTINY 的优化器在每个配置点最小化 WriteEDP。所得指标——面积、延迟、能耗、泄漏——均反映这一特定优化目标，并不代表完整设计空间的 Pareto 最优前沿。采用不同优化目标（ReadLatency、WriteLatency 或 LeakagePower），优化器将选择不同的组织方式，可能产生不同的缩放趋势和异常行为。65 nm 时 SRAM 的延迟突增与 32 nm 时的泄漏突增，均是 WriteEDP 优化的直接结果；在不同目标下，这些现象将以不同形式出现，甚至消失。基于本数据集得出的任何比较性结论，都应被理解为 WriteEDP 优化语境下的特定结果。

### 9.3 DESTINY 模型的范围与局限性

DESTINY 对存储阵列（单元、局部导线、全局 H 树）进行建模，但不捕获以下若干重要的实际效应：

1. **刷新开销（eDRAM）**：仿真器报告 eDRAM 的静态泄漏，但不计入周期性刷新操作消耗的动态能量。350 K 时，结区泄漏加剧导致保持时间退化，可能要求低于 40 µs 的刷新间隔，显著增加有效功耗。

2. **工艺变异与良率**：未对单元级参数变异（V_th 分布、接触电阻）进行建模。实际的 TSV 三维集成还引入额外的机械应力和键合良率问题，在精细节距下尤为显著。

3. **22 nm 外推**：DESTINY 的参数化模型经过制造工艺数据的标定，22 nm 时依赖内插和投影，而非测量的硬件数据。该节点的结果应作为模型预测值而非实验验证数据处理。

4. **单一优化目标**：本研究仅评估了 WriteEDP 优化。面向特定应用的优化可能实质性改变各技术的相对排名。

---

## 10. 结论

本研究在四个工艺节点（65–22 nm）上评估了四种存储器技术——2D SRAM、3D SRAM、2D eDRAM 和 3D eDRAM，并对 32 nm 下 3D SRAM 的 TSV 参数敏感性进行了表征。可以得出以下主要结论：

1. **面积缩放**：所有技术随节点缩减均实现面积降低，eDRAM 因其单晶体管单元拓扑获益多于 SRAM。3D eDRAM 实现最大的综合缩放（65 至 22 nm 共 14.1 倍），并在 22 nm 时取得最小绝对占用面积（0.550 mm²）。三维堆叠对 SRAM 提供稳定的约 40–50% 面积缩减，但在 65 nm 时对 eDRAM 带来面积惩罚（+30%），原因是 TSV 开销超过了裸片减半收益。

2. **读取延迟**：3D eDRAM 在所有节点取得最低延迟（0.42–0.54 ns），且严格单调改善。SRAM 在 65 nm 时呈现异常延迟突增（2D SRAM 高达 9.94 ns），归因于 WriteEDP 优化框架下优化器选择深度 H 树层次结构以响应大芯片面积——这是优化器诱导的设计点，而非技术的固有极限。

3. **写入能耗**：在 WriteEDP 优化下，写入动态能耗对所有技术均呈非单调变化，反映的是各节点间的配置重组，而非简单的电压和电容缩放。所有技术在 22 nm 时均收敛至 0.019–0.035 nJ/次，由供电电压缩放主导。

4. **泄漏功耗**：eDRAM 泄漏在大多数节点低于 SRAM 5–8 倍，直接源于 1T-1C 对比 6T 的单元拓扑差异。SRAM 在 32 nm 时出现急剧泄漏突增（2D 和 3D 均为 234.6 mW），归因于优化器为最小化写入 EDP 而选择的高并发度缓存组织，大幅提升了活跃晶体管数量。三维集成在所有情况下均增加泄漏功耗。

5. **TSV 敏感性**：在 2 MB 缓存规模和 32 nm 节点下，TSV 工艺假设对系统级指标影响甚微。最敏感的参数 LocalTSVProjection，在激进与保守投影之间至多使总面积增加 5.5%、写入能耗增加 6.7%，读写延迟则对所有 TSV 参数变化完全不敏感，表明关键时序路径未经过裸片间 TSV 堆叠。

综合而言，上述结论表明 3D eDRAM 是 32 nm 及以下节点、延迟与面积受限应用中最具吸引力的技术选项，而 2D eDRAM 在待机泄漏为主要约束时更为优选。基于 SRAM 的技术在刷新复杂性不可接受、且可承受其泄漏代价的场景中仍具相关性。TSV 工艺投影对系统指标的低敏感性，为使用保守建模假设评估三维存储器设计提供了充分依据，降低了因过于乐观预测而导致的设计风险。
